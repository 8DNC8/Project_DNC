## 二、循迹原理 - 核心详解

### 2.1 什么叫"循迹"？

循迹 = 让小车沿着地面上画的一条黑线走。

**难点在哪？**
- 小车不可能永远完美居中，总会偏
- 偏了以后要自动修正回来
- 修正力度要合适：太小→回不来，太大→冲过头→左右摆→失控
- 直角弯时车会冲出线外，需要特殊处理

### 2.2 传感器布局

```
              车头方向
                 ↑
   ┌─────────────┼─────────────┐
   │             ┃             │
   │   ┌───┐ ┌───┐ ┌───┐ ┌───┐│
   │   │S1 │ │S2 │ │S3 │ │S4 ││
   │   │-7 │ │-3 │ │+3 │ │+7 ││   ← 权重值
   │   └───┘ └───┘ └───┘ └───┘│
   │     │     │     │     │   │
   │   左边   左中   右中   右边  │
   └─────────────────────────────┘
```

**4个传感器从左到右排列：**

| 传感器 | 位置 | 权重 | 含义 |
|--------|------|------|------|
| S1 | 最左 | -7 | 检测到黑线 = 黑线在极左边 = 需要大力左转 |
| S2 | 左中 | -3 | 检测到黑线 = 黑线在偏左 = 需要轻微左转 |
| S3 | 右中 | +3 | 检测到黑线 = 黑线在偏右 = 需要轻微右转 |
| S4 | 最右 | +7 | 检测到黑线 = 黑线在极右边 = 需要大力右转 |

**为什么权重是不对称的？** 因为S1和S4离中心更远，偏差更严重，需要更大的修正力；S2和S3离中心近，轻微修正即可。

### 2.3 传感器如何检测黑线？

**红外反射原理：**

```
红外发射管 ──── 红外光 ────► 地面
                                │
                     ┌──────────┴──────────┐
                     │                     │
              黑线表面                  白地表面
              红外被吸收                红外被反射
              反射少                    反射多
                     │                     │
                     ▼                     ▼
              传感器输出高电平         传感器输出低电平
              s = 1 (检测到黑线)       s = 0 (白地)
```

**简单记：黑线吸光→反射少→高电平→s=1；白地反光→反射多→低电平→s=0**

### 2.4 误差计算 - 最核心的算法

误差（error）是整个控制系统的输入，它告诉小车"黑线偏离了多远、偏向哪边"。

#### 步骤1：加权求和

```
weighted = S1×(-7) + S2×(-3) + S3×(+3) + S4×(+7)
```

只有压线的传感器（s=1）会贡献权重，没压线的（s=0）不参与计算。

#### 步骤2：归一化

```
error = weighted / count    (count = 压线的传感器数量)
```

**为什么要除以count？** 因为1个传感器压线和3个传感器压线，weighted值差别很大。除以count后，无论几个传感器压线，error都在-7~+7范围内，方便后续统一处理。

#### 各种场景的error值：

```
场景1: 直道居中（S2和S3压线）
  S1=0, S2=1, S3=1, S4=0
  weighted = 0×(-7) + 1×(-3) + 1×(+3) + 0×(+7) = 0
  count = 2
  error = 0 / 2 = 0     ← 完美居中，不需要修正！

场景2: 黑线偏左一点（只有S2压线）
  S1=0, S2=1, S3=0, S4=0
  weighted = 0 + (-3) + 0 + 0 = -3
  count = 1
  error = -3 / 1 = -3   ← 负数，黑线在左，需要左转修正

场景3: 黑线严重偏左（只有S1压线）
  S1=1, S2=0, S3=0, S4=0
  weighted = (-7) + 0 + 0 + 0 = -7
  count = 1
  error = -7 / 1 = -7   ← 最大负值，黑线极左，需要大力左转

场景4: 黑线偏右（S3和S4压线）
  S1=0, S2=0, S3=1, S4=1
  weighted = 0 + 0 + 3 + 7 = 10
  count = 2
  error = 10 / 2 = +5   ← 正数，黑线偏右，需要右转修正

场景5: 全白（所有传感器都没压线）
  count = 0
  → 特殊处理！见2.5节
```

#### 误差含义总结：

| error值 | 含义 | 需要的动作 |
|---------|------|-----------|
| -7 | 黑线在最左 | 大力左转 |
| -3 | 黑线在偏左 | 轻微左转 |
| 0 | 黑线居中 | 直行 |
| +3 | 黑线在偏右 | 轻微右转 |
| +7 | 黑线在最右 | 大力右转 |

### 2.5 全白处理 - 掉线保护

**问题：** 当小车冲出赛道（直角弯、赛道中断），4个传感器全部读0（全白），count=0，无法用正常公式计算error。

**旧方案的问题：** `error = last_error × 2`
- 如果之前error=0（正在直行时突然掉线），那error还是0，车继续直行，冲得更远！

**当前方案：** 立即给大误差，强制转向找线

```
magnitude = 8 + all_white_count × 4     （第1次=8，第2次=12，第3次=16...）
上限 = 25

if (上次error ≥ 0) → error = +magnitude   （继续右转找线）
if (上次error < 0) → error = -magnitude   （继续左转找线）
```

**关键设计：**
- 第1次掉线就给8（足够大的值），不等
- 掉线越久，magnitude越大（8→12→16→20→25），转向越猛
- 方向由上次有效error决定：上次往右偏就继续右转找线

**为什么这样做？** 直角弯时，车头还没转过来就已经冲出了线。这时候必须按照之前偏转的方向继续猛转，才能找到线回来。

## 三、PD控制器 - 让车稳稳地走

### 3.1 为什么需要PD控制？

知道了error（偏差），最简单的做法是直接把error乘以一个系数去修正轮速。但这样会出问题：

- 只用P（比例项）：修正永远"慢一拍"，到达中心时还在修正，冲过头
- 加上D（微分项）：能"预测"趋势，到达中心前提前减速，减少振荡

**类比：**
- P = 看到偏了就修正（现在式）
- D = 看到偏得越来越快就提前修正（预测式）

### 3.2 P项（比例项）

```
correction_p = error × KP
```

- error越大 → 修正越强 → 转弯越猛
- KP是比例系数，决定修正力度

**举例：**
- error=3, KP=80 → correction_p = 240（中等修正）
- error=7, KP=100 → correction_p = 700（强力修正）

### 3.3 D项（微分项）

```
correction_d = (error - last_error) × KD
```

- 误差变化量 = 当前error - 上次error
- 误差在增大（偏离越来越快） → D项加强修正，阻止偏离
- 误差在减小（正在回到中心） → D项减弱修正，防止冲过头

**举例：**

| 时刻 | error | last_error | 变化量 | KD=15 | D项含义 |
|------|-------|------------|--------|-------|---------|
| T1 | -5 | -3 | -2 | -30 | 偏离在加剧，加大修正 |
| T2 | -3 | -5 | +2 | +30 | 正在回归，减小修正 |
| T3 | 0 | -3 | +3 | +45 | 快到中心了，大力减速 |

**D项的本质：** 它检测的是error的变化速度。变化越快，D项越大，作用就是"刹车"——防止车冲过头。

### 3.4 动态KP - 核心优化

**问题：** 一个固定的KP无法同时满足直道和弯道的需求：
- 直道需要小KP → 稳定不晃
- 弯道需要大KP → 转得过去

**解决方案：** 根据error大小自动切换KP值

| error范围 | KP值 | 场景 | 目的 |
|-----------|------|------|------|
| 0~1 | 80 | 直道 | 修正温和，走直线稳 |
| 2~4 | 80~100（插值） | 弯道 | 中等修正，平滑过弯 |
| ≥5 | 100 | 急弯/直角弯 | 强力修正，转得过去 |

**为什么KP不能太大？**
KP太大 → 修正过猛 → 车冲过头 → 反方向修正更猛 → 反复冲过头 → **S1/S2振荡**！
这就是为什么之前直道走不稳的根本原因。

### 3.5 自适应速度

**原则：** 弯道降速，直道全速

```
if (error < 2)       → speed = BASE_SPEED (260)  直道全速
if (error ≥ 2)       → speed 线性递减到 SPEED_MIN (120)
```

**为什么弯道要降速？**
1. 速度越快，转向响应越慢（惯性大）
2. 弯道时如果速度太快，车来不及修正就冲出去了
3. 降速后，同样的修正量效果更明显

### 3.6 差速转向

最后一步，把修正量（correction）变成左右轮的速度差：

```
左轮速度 = speed_factor + correction
右轮速度 = speed_factor - correction
```

**实例分析：**

| 场景 | error | correction | 左轮 | 右轮 | 效果 |
|------|-------|------------|------|------|------|
| 直行 | 0 | 0 | 260 | 260 | 两轮同速，直行 |
| 微右偏 | +1 | +80 | 340 | 180 | 左快右慢 → 右转修正 |
| 弯道 | +3 | +240 | 420 | 20 | 左快右几乎停 → 强力右转 |
| 直角弯 | +7 | +700 | 960 | -440 | 左转右反转 → 原地打转 |

**注意：** 当correction > speed_factor时，一个轮会变成负值（反转），实现原地转弯。这是过直角弯的关键！

## 四、超声波避障

### 4.1 测距原理

HC-SR04超声波模块通过发射超声波并接收回波来测量距离：

```
距离 = 声速 × 传播时间 / 2
     = 346m/s × 时间 / 2
```

除以2是因为超声波走的是往返路程。

### 4.2 避障逻辑

在每次循迹控制前，先检查前方距离：

```c
#define OBSTACLE_DIST  150    // 改这个值调避障距离！单位mm

if (g_front_dist > 0 && g_front_dist < OBSTACLE_DIST)
{
    停车;    // 不执行循迹
    return;
}
```

**参数调整：**
| OBSTACLE_DIST值 | 含义 | 适用场景 |
|-----------------|------|---------|
| 100 | 10cm | 窄空间，反应快 |
| 150 | 15cm | 默认值，平衡 |
| 200 | 20cm | 保守，留余量 |
| 300 | 30cm | 很保守，远距离停车 |

### 4.3 OLED状态显示

当避障停车时，OLED第4行显示 `!!STOP!!`，第1行的M值变为2。

## 五、完整控制流程

```
每5ms执行一次：

┌──────────────────────────────────────────────┐
│ ① 读超声波距离（上次值，每100ms更新一次）        │
│    ↓                                          │
│ ② 距离 < 150mm？ ──是──→ 停车，显示!!STOP!!    │
│    │否                                        │
│    ↓                                          │
│ ③ 读4路红外传感器 → S1,S2,S3,S4              │
│    ↓                                          │
│ ④ 计算error                                  │
│    │ 全白？→ 激进找线策略（error=±8~25）        │
│    │ 正常？→ 加权求和 ÷ count                  │
│    ↓                                          │
│ ⑤ 动态KP计算                                 │
│    error 0~1 → KP=80                          │
│    error 2~4 → KP=80~100                      │
│    error ≥5  → KP=100                         │
│    ↓                                          │
│ ⑥ PD计算                                     │
│    correction = error × KP + (error-last) × KD│
│    ↓                                          │
│ ⑦ 自适应速度                                  │
│    error小 → 全速260                          │
│    error大 → 降速到120                        │
│    ↓                                          │
│ ⑧ 输出到电机                                  │
│    左轮 = speed + correction                  │
│    右轮 = speed - correction                  │
└──────────────────────────────────────────────┘

每100ms额外执行：
  - 超声波测距 → 更新g_front_dist
  - OLED刷新显示
```

## 七、常见问题与调参

### Q1: 直道走不稳，左右晃
**原因：** KP太大或KD太小
**解法：** 降低动态KP各档位，或增大KD

### Q2: 直角弯转不过去
**原因：** 修正力不够或速度太快
**解法：** 增大error≥5时的KP值，或降低SPEED_MIN

### Q3: 弯道走S形（过冲振荡）
**原因：** KP太大导致修正过猛
**解法：** 降低动态KP，增大KD

### Q4: 避障距离太近/太远
**解法：** 修改 `OBSTACLE_DIST` 的值，单位是mm

### Q5: 上电瞬间轮速不对称
**原因：** 首次D项计算时last_error=0，会产生突变
**解法：** 代码中已有first_call标志，首次D项=0，如果还有问题可增大D项初始化延迟
