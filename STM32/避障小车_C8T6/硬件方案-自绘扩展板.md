# 软通赛题 Hi3863 硬件方案 —— 自绘扩展板路线

> 适用：嵌入式芯片与系统设计竞赛 · 软通赛题（SwanLinkOS/OpenHarmony）· 选题方向：星闪物联网 / 自主选题（鼓励 RISC-V + 星闪）
> 主控：BearPi-Pico H3863（WS63 / Hi3863V100，RISC-V 240MHz + FPU + 4MB Flash，星闪 SLE + WiFi6 + BLE 三模）

---

## 1. 结论：DEV 底板与 E53 模块非强制，参赛不受影响

### 1.1 赛题规则依据（已查实）
- 海思官方 2026 嵌赛选题指南「选题一·星闪物联网应用方向」：**主控优先使用 WS63 / WS63E / BS21**，操作系统可用 LiteOS 或 OpenHarmony。
- 软通赛道要求作品须基于 **SwanLinkOS/OpenHarmony** 自主设计，**特别鼓励结合 RISC-V 架构与星闪通信技术**。
- **全程只约束「主控芯片」与「操作系统」，从不约束底板厂商、E53 模块、传感器来源。**

### 1.2 BearPi-Pico H3863 已具备的能力（无需 DEV 底板即可开发）
| 项目 | 现状 |
|---|---|
| 烧录/供电/串口 | 板载 USB-C（内置 USB 转 UART），无需外部下载器 |
| 指示灯 | 电源 LED（红）+ 用户 LED（蓝） |
| 复位 | 复位键 |
| 引出 GPIO | **17 路排针**，含 I2C×2 / SPI×2 / QSPI×1 / UART×3 / PWM×8 / ADC×6 / I2S×1 |
| 天线 | 板载 PCB 天线 + IPX 外接座 |
| SWD | SWCLK=GPIO14，SWDIO=GPIO13（排针第 8/9 脚） |

**结论**：PICO 核心板本身就是一块完整开发板。DEV 底板只是软通官方套装的扩展板（带 E53 接口/更多传感器），属加分项而非必选项。买不到 ≠ 做不了。

---

## 2. 自绘扩展板方案（推荐，体现硬件自主，国奖加分）

你要画的是**外设扩展板**（最小系统已由 PICO 核心板承担），核心任务：把 PICO 排针的总线引出 + 挂载必要外设。

### 2.1 自绘扩展板最小引脚清单（功能级）
> 具体物理排针编号以 bearpi.cn 官方原理图 `BearPi-H3863_Pico.pdf` 为准，下表为功能分配建议。

| 类别 | 需引出 | 用途 |
|---|---|---|
| 电源 | 3.3V ×2、5V ×1、GND ×3 | 给传感器/外设供电 |
| I2C | I2C0、I2C1（各 SDA/SCL） | OLED(0.96/1.3寸)、加速度计、温湿度 |
| SPI | SPI×1（CLK/MOSI/MISO/CS） | 高速传感器/扩展 |
| UART | UART×1（TX/RX） | 接天问Block 语音 / MSPM0 节点 |
| ADC | ADC×2 | 模拟量传感器（振动包络/温度） |
| PWM | PWM×2 | 蜂鸣器、电机调速 |
| GPIO | 通用×4 | 按键、状态灯、急停继电器 |
| SWD | 预留 GPIO13/14 | 调试（可选） |

### 2.2 板上建议挂载
- **OLED 显示屏**：0.96 寸 I2C（SSD1306），本地状态显示。
- **用户按键 ×2**：模式切换 / 告警确认。
- **有源蜂鸣器 ×1**：本地声光告警（PWM 驱动）。
- **传感器插座排母**：加速度计、温度计直插或飞线。

### 2.3 传感器选型与采购（裸片即可，不必买 E53 模块）
| 器件 | 用途 | 接口 | 参考价 |
|---|---|---|---|
| ADXL345 / MPU6050 | 振动加速度采集 | I2C/SPI | ¥10–25 |
| DS18B20 / MAX31865+PT100 | 轴承/绕组温度 | 1-Wire/SPI | ¥15–40 |
| 小直流电机+轴承台 | 制造正常/异常工况演示 | — | ¥30–80 |
| 排针/杜邦线/洞洞板 | 接线 | — | ¥10 |

## 3. 两条路径对比

| 路径 | 做法 | 优劣 |
|---|---|---|
| **A. 自绘扩展板（推荐）** | PICO核心板 + 自画外设扩展板 + 裸传感器 | 体现硬件自主（国奖高分）；成本极低（打板￥30–60）；需下载原理图核对引脚 |
| **B. 进群买官方套装** | 赛题官方 QQ 群 991213854 问软通教育淘宝店链接 | 即插即用、与示例 100% 匹配；但渠道受限、可能排队/限量、成本略高（完赛或可申请退款） |

> 立创开源有现成 Hi3863 开发板工程（oshwhub，复刻 ¥19.9，含 CH340），其底板设计可直接参考抄板，降低自绘风险。

## 4. 下一步行动（按顺序）

1. **下载 BearPi-Pico H3863 原理图**：`https://www.bearpi.cn/core_board/bearpi/pico/h3863/`（含引脚复用表），核对 PICO 排针与 2.1 清单的物理映射。
2. **确定路径 A 或 B**（建议 A）。
3. **装 HiSpark Studio / XFusion**（VS Code 插件，Linux 环境），先点官方 Blinky 跑通烧录。
4. **采购传感器**（见 2.3），与画板同步进行。
5. 软件稳后，再换自绘扩展板，定位问题最快。

## 5. 系统架构（参赛用，方向=工业预测性维护）
```
[Hi3863 星闪套装 = 主控+星闪网关]  BearPi-Pico H3863 + 自绘扩展板
   · 收星闪数据 → FFT + 轻量分类（边缘AI, RISC-V 240MHz+FPU）
   · 本地 OLED 显示 + WiFi6 上云/手机端
        │ 星闪 SLE
[终端节点]  MSPM0G3507 + 加速度计+温度计 → M528H-WS63（真 WS63）
        │ UART
[天问Block 语音告警]  ← Hi3863 指令播报
（可选）[STM32F103 执行器] ← 急停/报警继电器闭环
```
