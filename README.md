## 🚀 如何使用

### 克隆仓库

```bash
git clone https://github.com/8DNC8/Project_DNC.git
cd Project_DNC
```

### 编译与烧录

1. 进入对应项目目录
2. **Keil 工程**：用 Keil MDK-ARM 5 打开 `.uvprojx` 工程文件，编译后通过 ST-Link / J-Link 烧录
3. **e² studio 工程**（瑞萨项目）：用 e² studio 导入工程目录，编译后烧录
4. **Keil C51 工程**：用 Keil C51 打开 `.uvproj` 工程文件
5. **Proteus 仿真**：用 Proteus 打开 `.epro2` 文件运行仿真

> 部分项目目录下附有文档说明（如硬件方案、答辩讲稿等），可参考。

## ⚠️ 注意事项

- 部分项目使用了第三方库（STM32 HAL 库、标准外设库、瑞萨 FSP 库、逐飞科技库等），版权归原作者所有
- 竞赛项目仅供学习交流参考，请勿直接照搬参赛
- 编译产物（`Objects/`、`Listings/`、`Debug/`、`build/` 等）已通过 `.gitignore` 忽略，首次编译需重新生成
- Proteus 仿真工程文件 (`.epro2`) 需要对应版本的 Proteus 软件打开
